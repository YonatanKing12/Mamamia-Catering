# מאמא מיה קייטרינג

דף נחיתה לגיוס לידים לקייטרינג של מאמא מיה — הרצליה פיתוח, רעננה ופתח תקווה.

## הרצה מקומית

```bash
npm install
npm run dev          # http://localhost:3000
```

זה עובד מיד אחרי clone, בלי מסד נתונים ובלי הגדרות. לידים נשמרים בזיכרון
התהליך ונמחקים ב־restart — תקין לפיתוח, לא לפרודקשן.

## סקריפטים

| פקודה | מה הוא עושה |
|---|---|
| `npm run dev` | שרת פיתוח עם HMR ורענון אוטומטי של השרת |
| `npm run build` | בונה את הקליינט ל־`dist/public` ואת השרת ל־`dist/index.js` |
| `npm start` | מריץ את הבילד בפרודקשן |
| `npm run check` | בדיקת טיפוסים |
| `npm run db:push` | דוחף את הסכימה למסד (דורש `DATABASE_URL`) |
| `npm run db:studio` | ממשק לעיון במסד |

## משתני סביבה

העתיקו `.env.example` ל־`.env`. אף אחד מהם אינו חובה לפיתוח.

| משתנה | חובה | תפקיד |
|---|---|---|
| `PORT` | לא | ברירת מחדל 3000 |
| `DATABASE_URL` | **בפרודקשן** | כל Postgres. בלעדיו הלידים נדיפים |
| `ADMIN_TOKEN` | **לצפייה בלידים** | 24 תווים ומעלה. בלעדיו `/api/leads` מושבת |
| `NOTIFY_WEBHOOK_URL` | **בפרודקשן** | כל ליד נשלח לשם מיד. בלעדיו אף אחד לא מקבל התראה |

## API

| נתיב | הרשאה | תפקיד |
|---|---|---|
| `GET /api/health` | פתוח | בדיקת חיים + מצב המסד |
| `POST /api/contact` | פתוח, 8 בקשות ל־10 דקות לכל IP | קליטת ליד |
| `GET /api/leads` | `Authorization: Bearer $ADMIN_TOKEN` | כל הלידים |

## אבטחה — לקרוא לפני העלייה לאוויר

הגרסה המקורית חשפה **את כל הלידים לכל אדם באינטרנט** דרך `GET /api/contact`
ללא שום אימות: שם, טלפון, מייל, סוג אירוע, תאריך והערות. הנתיב הוסר.

הכללים שמחזיקים את זה סגור:

- `GET /api/leads` דורש `ADMIN_TOKEN` באורך 24 תווים ומעלה. **בלי טוקן מוגדר
  הנתיב מחזיר 503 ולא נפתח** — אי אפשר להשאיר אותו פתוח בהיסח הדעת.
- ההשוואה נעשית ב־`timingSafeEqual`, ותשובות עם מידע אישי מסומנות `no-store`.
- גוף התשובות לא נרשם ביומן, כדי שטלפונים של לקוחות לא יגיעו ללוגים של הספק.
- `.env` ב־`.gitignore`. אל תשנו את זה — הריפו ציבורי.

בישראל המידע הזה כפוף לחוק הגנת הפרטיות. תיקון 13 נכנס לתוקף ב־2025 עם
סנקציות ממשיות על דליפה, ובעל השליטה במידע הוא בעל העסק.

## תוכן — מה אסור

`server/seed.ts` המקורי הזריע **המלצות בשמות אנשים שלא קיימים**, פוסטי בלוג
ופריטי גלריה מומצאים. על אתר של עסק אמיתי אלה ביקורות כזב — הטעיית צרכן.
התוכן הומצא הוסר.

הזרעה עובדת עכשיו מ־`content/seed.json`, וכל המלצה חייבת `consentGiven: true`
— אישור מפורש של הלקוח לשימוש בשמו. אין קובץ, לא מוזרק כלום.

שני דברים נוספים שממתינים לאימות מול הדוד לפני שהם חוזרים לדף:

- **תג הכשרות.** בקוד המקורי היה `כשר בד"ץ` קבוע ב־hero, ו־`כשר בדץ מהדרין`
  ב־meta keywords. בד"ץ היא הסמכה ספציפית. חייב אישור מדויק, או שזה יורד.
- **מחירי מחשבון ההצעה.** התעריפים המקוריים הומצאו (₪120 לסועד לחתונה,
  מכפיל 1.6, ₪500 מלצרים, 15% סופ"ש). כל ליד היה מגיע מעוגן במספר שגוי.

## מה נותק מרפליט

| מה | למה |
|---|---|
| `.replit`, `replit.md`, `.agents/` | קונפיגורציה של הפלטפורמה |
| `@replit/vite-plugin-cartographer`, `-runtime-error-modal` | פלאגינים שקיימים רק שם |
| `replit-dev-banner.js` ב־`client/index.html` | סקריפט חיצוני מוזרק |
| `reusePort: true` ב־`server.listen` | **זורק ENOTSUP על macOS ו־Windows** — הפרויקט לא היה עולה מחוץ ללינוקס של רפליט |
| פורט 5000 | תפוס ב־macOS על ידי AirPlay. עבר ל־3000 |
| `@neondatabase/serverless` | הוחלף ב־`pg` — עובד מול כל Postgres |
| Secrets של רפליט | `.env` דרך `dotenv` |
| `reference/`, `attached_assets/` | 97MB של עצים מוכפלים וקבצי zip |

תוקנו גם: `target` חסר ב־`tsconfig` (נפל ל־ES5), `maximum-scale=1` שחוסם
זום בפינץ' בניגוד ל־WCAG 1.4.4, ו־error handler ששלח תשובה ואז זרק מחדש
וכך הפיל את התהליך.

## פריסה

הפרויקט הוא שרת Node שמגיש גם את הקליינט — כלומר צריך אחסון שמריץ תהליך
(Railway, Render, Fly, VPS), לא אחסון סטטי.

```
build:  npm run build
start:  npm start
```

צריך `DATABASE_URL`, `ADMIN_TOKEN` ו־`NOTIFY_WEBHOOK_URL` בהגדרות הספק,
ו־`npm run db:push` פעם אחת ליצירת הטבלאות.

## מבנה

```
client/          React + Vite + Tailwind + shadcn/ui
  src/components/sections/    סקציות הדף
  src/data/                   תוכן סטטי
server/          Express — API, הגשת הקליינט
shared/schema.ts  סכימת Drizzle, מקור אמת אחד לטיפוסים
docs/design-reference/        כיוון עיצובי סטטי לייבוא לתוך React
```

`docs/design-reference/` הוא דף HTML עובד בכיוון העיצובי המכוון —
נייר, טיפוגרפיה עריכתית, מחשבון הצעה שלא מציג מספר שלא אושר. הוא לא נפרס;
הוא המקור שממנו מיוצרת שפת העיצוב אל תוך הקומפוננטות.
