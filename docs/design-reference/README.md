# מאמא מיה קייטרינג — דף נחיתה

דף נחיתה סטטי בעברית (RTL) לגיוס לידים לקייטרינג של מאמא מיה — הרצליה פיתוח, רעננה ופתח תקווה.

בלי build, בלי פריימוורק, בלי תלויות: שלושה קבצים שנטענים מהר ועובדים בכל מקום.

```
index.html              כל התוכן והמבנה (SEO מלא — הטקסט בעברית ישר ב־HTML)
assets/css/style.css    מערכת העיצוב
assets/js/site.js       מחשבון ההצעה, וואטסאפ, חשיפה בגלילה
```

## הרצה מקומית

```bash
python3 -m http.server 8000
# ואז: http://localhost:8000
```

## מה צריך למלא לפני העלייה לאוויר

כל מה שחסר מסומן בדף ב**הדגשה צהובה** ובקוד בתוך `{{ }}`, כך שאי אפשר לפספס.
מציאת כל מה שנשאר:

```bash
grep -o '{{[A-Z_0-9]*}}' index.html | sort -u
```

### 1. שני מספרים ב־`assets/js/site.js`

```js
const CFG = {
  whatsapp: '972501234567',        // בינלאומי, בלי + ובלי מקפים
  tel:      '050-1234567',         // מה שמוצג בדף
  perPerson: { min: 90, max: 180 },// טווח מחיר לסועד, בשקלים
};
```

**`perPerson`**: כל עוד אחד מהערכים הוא `null`, מסך "הערכת טווח" **לא מוצג בכלל**.
זה מכוון — כדי שלעולם לא יופיע מספר שדוד שלך לא אישר. ברגע שממלאים, ההערכה נדלקת אוטומטית.

### 2. הטוקנים ב־`index.html`

חיפוש והחלפה של כל אחד:

| טוקן | מה למלא |
|---|---|
| `{{TEL}}` / `{{TEL_HREF}}` | טלפון להצגה / לחיוץ |
| `{{EMAIL}}` | מייל לפניות קייטרינג |
| `{{YEARS}}` | כמה שנים העסק פועל |
| `{{MAX_GUESTS}}` | מקסימום סועדים שאתם לוקחים |
| `{{MIN_GUESTS}}` | מינימום סועדים |
| `{{PRICE_1..3}}` | מחיר פתיחה לסועד לכל תפריט |
| `{{PRICE_RANGE}}` | טווח ל־schema, למשל `₪₪` |
| `{{ADDR_HERZLIYA}}` `{{ADDR_RAANANA}}` `{{ADDR_PETAH}}` | כתובות שלושת הסניפים |
| `{{OWNER_STORY}}` | 3–4 שורות אמיתיות על הדוד והמטבח |
| `{{FAQ_KOSHER}}` | תשובת הכשרות — **השאלה הראשונה של כל לקוח** |
| `{{FAQ_PAYMENT}}` | תנאי תשלום וביטול |
| `{{LEAD_TIME}}` | זמן הזמנה מראש, למשל `שבוע` |
| `{{CHANGE_WINDOW}}` | עד מתי משנים מספר סועדים, למשל `72 שעות` |
| `{{EVENT_1..3_*}}` | שלושה אירועים אמיתיים — ראו אזהרה למטה |
| `<link rel="canonical">` | הדומיין האמיתי |

> **סיפורי האירועים והציטוטים — רק דברים אמיתיים.**
> השארתי אותם ריקים בכוונה ולא כתבתי טקסט לדוגמה, כי ציטוט מומצא בשם לקוח
> שלא אמר אותו הוא בעיה אמיתית לעסק קיים. תבקש מהדוד שלוש הודעות וואטסאפ
> אמיתיות מלקוחות מרוצים ואישור להשתמש בשם הפרטי. זה החלק שממיר הכי חזק בדף,
> ושווה את שיחת הטלפון.

### 3. תמונות

ראו `assets/images/README.md` למידות ולרשימה המדויקת.
עד שיהיו תמונות, הדף מציג מסגרות עם שם התמונה הדרושה — נראה מכוון, לא שבור.

### 4. כיבוי סימוני העריכה

כשהכול מלא, מוסיפים `class="live"` ל־`<body>` וההדגשות הצהובות והערות ה־TODO נעלמות:

```html
<body class="live">
```

## איפה נופלים הלידים

הטופס עובד בשתי דרכים במקביל, וזה מכוון — מי שלא ממלא טופס כן שולח וואטסאפ:

1. **Netlify Forms** — `data-netlify="true"` על הטופס. בפריסה ל־Netlify זה נקלט
   אוטומטית תחת שם הטופס `catering-lead`, בלי שורת קוד בצד שרת. הגדירו
   התראת מייל ב־Netlify → Forms → Notifications.
2. **וואטסאפ** — כפתור שבונה הודעה מוכנה עם כל התשובות, כך שהליד מגיע עם הקשר
   ולא כ־"היי מה המחיר".

שדה `source_url` נשלח אוטומטית, כך שפרמטרי UTM מקמפיינים נשמרים עם כל ליד.
מלכודת בוטים (honeypot) מוגדרת דרך `netlify-honeypot="bot-field"`.

> **מהירות תגובה קובעת יותר מהדף.** ליד קייטרינג שלא נענה תוך חצי שעה כבר
> מדבר עם מישהו אחר. שווה להגדיר התראת פוש לטלפון של מי שעונה.

## פריסה

```bash
# Netlify — גרירת התיקייה, או:
npx netlify deploy --prod --dir .
```

אתר סטטי לגמרי, אז כל הוסטינג יעבוד (Netlify / Cloudflare Pages / Vercel /
GitHub Pages). אם לא Netlify — צריך להחליף את יעד הטופס: או `action` לשירות
טפסים אחר, או פונקציה קטנה שמעבירה למייל.

## נגישות ובדיקות שכבר נעשו

- `lang="he"` + `dir="rtl"`, לוגי־פרופרטיז ב־CSS (`inset-inline`) כך שהפריסה נכונה בעברית
- ניווט מלא במקלדת, `:focus-visible` נראה, `aria-live` על מצב המחשבון
- כיבוד `prefers-reduced-motion`
- הטופס עובד גם בלי JavaScript (כל השלבים פשוט מוצגים יחד)
- שדה `honeypot`, `rel="noopener"` על קישורים חיצוניים
- JSON-LD מסוג `FoodEstablishment` עם שלושת הסניפים ואזורי שירות — לחיפוש מקומי

## מה עוד כדאי, אחרי שהדף באוויר

- **גרסאות לפי אזור** — שלושה דפים כמעט זהים ל"קייטרינג הרצליה", "קייטרינג רעננה",
  "קייטרינג פתח תקווה". שלושת הסניפים הם יתרון SEO אמיתי שהמתחרים לא יכולים לזייף.
- **תפריט PDF להורדה תמורת טלפון** — לוכד את מי שאוסף הצעות ועדיין לא בשל.
- **מדידה** — GA4 או Plausible, עם אירוע נפרד על כל שלב במחשבון. משם רואים איפה נוטשים.
