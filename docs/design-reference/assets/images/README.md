# תמונות

עד שהתמונות האמיתיות מגיעות, הדף מציג מסגרת עם שם התמונה הדרושה.
זה נראה מכוון ולא שבור, אז אפשר להעלות לאוויר גם לפני.

## מה צריך

| קובץ | מידות | מה בתמונה |
|---|---|---|
| `hero.jpg` | 1400×1750 (4:5) | מנה מוגשת או המטבח בעבודה. התמונה החשובה ביותר בדף. |
| `kitchen.jpg` | 900×1200 (3:4) | המטבח בבוקר, לפני שהכול מתמלא. |
| `hands.jpg` | 900×700 (9:7) | ידיים בעבודת הכנה — לישה, חיתוך, סידור מגש. |
| `og.jpg` | 1200×630 | לשיתוף בוואטסאפ ובפייסבוק. שם המסעדה קריא. |

## הנחיות צילום

הבריף העיצובי הוא **אותנטי, לא זוהר**. לכן:

- **טלפון עם אור טבעי עדיף על סטוק.** באמת. תמונת סטוק של בופה מזוהה מיד ושורפת אמון.
- **אור מהצד, לא פלאש.** ליד חלון בבוקר.
- **מותר בלגן.** מגבת על הכתף, קמח על השיש, ידיים מלוכלכות — זה בדיוק מה שמוכר.
- **פנים אמיתיים** של הדוד ושל השף שווים יותר מכל תמונת אוכל.
- **בלי פילטרים** ובלי רוויה מוגזמת. הפלטה של הדף חמה ומאופקת, ותמונה צעקנית תילחם בה.

## אופטימיזציה לפני העלאה

```bash
# איכות טובה בערך בשליש מהמשקל
for f in *.jpg; do cwebp -q 82 "$f" -o "${f%.jpg}.webp"; done
```

כל תמונה מעל ~300KB פוגעת בקצב הטעינה, ובמובייל זה יורד ישר בהמרה.

## החלפה בקוד

ב־`index.html`, כל מקום לתמונה נראה כך:

```html
<figure class="photo" data-photo="תמונת נושא · 1400×1750">
  <!-- החליפו את ה־div הזה ב־: <img src="..." alt="..."> -->
</figure>
```

מוסיפים את ה־`<img>` בפנים ומוחקים את `data-photo`. ה־CSS מסתיר את התווית
אוטומטית ברגע שיש `img` בפנים. **לא לשכוח `alt` בעברית** — גם לנגישות וגם לגוגל.
